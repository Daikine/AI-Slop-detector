# Kirusha AI Email Detector — обновлённый гибридный классификатор (v2)

**Главная инструкция:** [README_V2_RU.md](README_V2_RU.md)  
**Список изменений и результаты тестов:** [CHANGELOG_V2_RU.md](CHANGELOG_V2_RU.md)

Конфигурация `.env.example` использует `API_KEY`, `API_URL` и `MODEL` для Qwen Chat API; впиши выданный командой ключ в локальный `.env`. Не коммить `.env` и не вставляй настоящий ключ в `.env.example`.

Это экспериментальная оценка вероятного ИИ-авторства текста, **не доказательство происхождения письма**. Датасет содержит примеры с разными источниками и эпохами: качество на реальных новых письмах отдельно не подтверждено.

Письмо для проверки можно ввести **одной строкой** в `10_QWEN_ENV_LLM_TEXT.bat` и нажать Enter.

Быстрый запуск в **уже настроенном** проекте Windows с LM Studio:

1. `03_LOCAL_QWEN_CHECK.bat` — проверить локальные Qwen embeddings.
2. `04_LOCAL_QWEN_TRAIN.bat` — обучить **новую v2 модель без TF-IDF**, на Qwen embeddings + контекстных признаках + дереве.
3. `05_LOCAL_QWEN_TEXT.bat` — ввести текст письма одной строкой и нажать Enter.
4. `07_LOCAL_QWEN_TRAIN_WITH_LLM.bat` — **необязательно**, загрузить chat-модель Qwen в LM Studio и вписать её ID; создать второе дерево с LLM-признаками.

Старая обученная модель и старый скрипт сохранены (`model/`, `model_local_qwen/`), новый результат находится в `model_hybrid_qwen/`. `.env`, виртуальные окружения и сам Qwen **не входят** в архив: они остаются на твоём ПК.
